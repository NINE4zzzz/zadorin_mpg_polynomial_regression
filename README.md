# Домашнее задание: Полиномиальная регрессия (Auto MPG)

Прогнозирование расхода топлива (`mpg`) по техническим характеристикам автомобиля,
Университет Иннополис, дисциплина «Инженер-архитектор в сфере искусственного интеллекта».

## Файлы

- `mpg_polynomial_regression.ipynb` — основной ноутбук со всеми пятью частями задания.

## Что сделано по частям

1. **Загрузка и EDA.** Датасет загружается как `pd.read_csv('auto-mpg.csv')`; если файла
   нет — ноутбук сам пытается скачать его с Kaggle (`kagglehub`), а если это недоступно
   без учётных данных — берёт ту же структуру данных из открытого зеркала на GitHub и
   сохраняет как `auto-mpg.csv`. Пропуски в `horsepower` (6 из 398, значения `?`)
   заполнены медианой; `car name` удалён; `cylinders`, `model year`, `origin` переведены
   в `category`. Построены корреляционная матрица и pairplot, найдены топ-3 признака по
   корреляции с `mpg` (`weight`, `displacement`, `cylinders`) и описана нелинейность связи.
2. **Baseline.** Train/test = 80/20 (`random_state=42`), масштабирование только
   непрерывных признаков, категориальные — через `pd.get_dummies`. Обычная линейная
   регрессия как точка отсчёта.
3. **Подбор степени полинома.** Пайплайн `StandardScaler → PolynomialFeatures →
   LinearRegression` внутри `ColumnTransformer` (полиномы только для непрерывных
   признаков), `validation_curve` по степеням 1–10, 5-кратная кросс-валидация, выбор
   степени по минимуму MSE на валидации.
4. **Ridge и Lasso.** Кривые валидации по `alpha` (0.001…100, 10 значений,
   log-шкала) на оптимальной степени; подбор оптимального `alpha` для каждой модели;
   анализ обнулённых Lasso-коэффициентов (порог `1e-6`).
5. **Итоговое сравнение.** Baseline / полином / Ridge на тестовой выборке, таблица
   MSE и R², развёрнутые ответы на все три вопроса задания и краткое резюме.

## Как запустить

Открыть `mpg_polynomial_regression.ipynb` в Google Colab (или локальном Jupyter) и
выполнить все ячейки по порядку (Runtime → Run all).

## Примечание по параметрам

В присланных материалах разделение выборки было описано двумя способами (70/30 в
основном тексте задания и `test_size=0.2, random_state=42` в более подробном
техническом брифе). В ноутбуке использован явно заданный `test_size=0.2,
random_state=42` — при необходимости строгого 70/30 достаточно поменять `test_size` в
ячейке разделения выборки (Часть 2.1).
